    Privasi & Keamanan Data (Client-Side)

    BioTools memproses seluruh sekuens Anda secara lokal (di dalam browser perangkat Anda) menggunakan JavaScript murni. Data Anda tidak pernah diunggah ke server mana pun, menjamin keamanan mutlak untuk data genomik eksklusif atau paten yang belum dipublikasikan. *Pengecualian hanya berlaku pada modul NCBI BLAST yang harus berkomunikasi dengan server E-Utilities NCBI.*

    Tips Penggunaan Cepat

    • MSA & Visualisasi: Hasil penjajaran ganda (MSA) menampilkan asam amino/nukleotida yang diberi kode warna standar. Klik "Salin ke Word" untuk mengopi format tersebut langsung ke laporan Anda.
    • Kustomisasi Filogenetik: Anda dapat mengganti warna garis, tipe font, hingga kemiringan teks (*Italic* sangat berguna untuk penulisan nama latin spesies) di bilah alat Filogenetik sebelum mengeklik tombol *Fullscreen* atau mengekspor ke *PNG*.
    • ORF & Proteomik: Gunakan ORF Finder untuk mengekstrak urutan basa penyandi, lalu salin hasil translasinya ke tab "Fisikokimia Protein" untuk mengetahui berat molekul (kDa) dan sifat asam/basanya (pI).
