Cara Menggunakan GeoPlot

GeoPlot adalah generator tata letak kartografi client-side. Semua data yang Anda masukkan diproses murni di perangkat Anda tanpa dikirim ke server (100% Privat).

  • Menambah Stasiun: Anda dapat memasukkan koordinat Lintang/Bujur secara manual di "Blok 4", mengaktifkan fitur 🎯 Klik Tambah Titik di "Blok 3", atau menekan tombol 📡 Deteksi GPS jika Anda sedang berada di lapangan.
  • Mengukur Jarak & Luas: Aktifkan 📏 Penggaris Jarak & Area. Klik titik-titik di peta untuk membentuk garis ukur. Klik ganda (Double-Click) untuk mereset ukuran.
  • Kustomisasi Simbol: Anda bisa memilih ikon stasiun (Lingkaran, Persegi, Segitiga) dan menambahkan Radius Buffer (misal 500m) untuk mensimulasikan zona dampak limbah.
  • Skala Presisi: Gunakan fitur "Kunci Skala 1 : X" (misal ketik 50000) untuk memfokuskan peta sesuai standar jurnal ilmiah.

Merombak metode *rendering* Leaflet dari Canvas kembali ke SVG untuk mengatasi bug *blank tiles* dan akurasi saat kanvas berubah ukuran. Pemindahan tata letak tombol Ekspor PNG.

Evolusi besar. Penambahan fitur Buffer Zones (Radius Zonasi), variasi Simbologi Marker (Persegi/Segitiga), Alat Penggaris Interaktif, dan dukungan penuh Impor/Ekspor GeoJSON & CSV.
v9.0 — Interactive Data Management
Penghapusan input textarea mentah. Digantikan dengan UI Formulir Mini dan Tabel Interaktif yang sangat ramah pengguna. Fitur input skala absolut (1:X Calculator).
v3.0 - v8.0 — Cartographic Perfection
Perombakan total dari sekadar web map menjadi *Print Layout* QGIS. Desain viewport 100vh tanpa scroll vertikal. Skala Zebra gaya ArcGIS. Tambahan basemap spesifik akuakultur (Esri Ocean Base).
