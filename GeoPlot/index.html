Cara Menggunakan GeoPlot

GeoPlot adalah generator tata letak kartografi client-side. Semua data yang Anda masukkan diproses murni di perangkat Anda tanpa dikirim ke server (100% Privat).

  • Menambah Stasiun: Anda dapat mengisi baris teratas di tabel "Kelola Data Stasiun", lalu menekan tombol (➕). Atau, aktifkan 🎯 Klik Tambah Titik di Blok 3 lalu mengeklik langsung di atas peta.
  • Edit Tabel Langsung: Tabel di Blok 4 bersifat interaktif! Klik nilai koordinat, ketik kategori baru, atau klik ikon warna untuk mengubah warna *marker* secara seketika di peta.
  • Mengukur Jarak & Luas: Aktifkan 📏 Penggaris Jarak & Area. Klik titik-titik di peta untuk membentuk garis ukur. Klik ganda (Double-Click) untuk mereset ukuran.
  • Skala Presisi: Gunakan fitur "Kunci Skala 1 : X" (misal ketik 25000) untuk memfokuskan peta sesuai standar jurnal ilmiah.
