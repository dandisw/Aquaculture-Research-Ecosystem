Tentang ShifterAI

ShifterAI adalah "Otak Sintesis" dari Aquaculture Research Ecosystem (AREs)[cite: 2]. Aplikasi ini dirancang untuk membaca keluaran format tabular atau teks dari aplikasi saudara (seperti StatWise, BioTools, dan EcoMetrics) dan mengubahnya menjadi narasi akademik yang koheren.

Cara Kerja Serverless Proxy

  • CSV/XLSX (Data Tabular): Mengekstrak baris data dan menugaskan Python (Pyodide) secara lokal untuk melakukan fungsi aglomerasi dan korelasi guna menghemat beban pemrosesan ke AI server.
  • PDF/DOCX/TXT (Teks Dokumen): Sistem mengekstrak layer teks menggunakan pdf.js[cite: 2], kemudian mengirimkan kerangka teks ke mesin backend Vercel untuk disusun menjadi paragraf ringkasan (executive summary) melalui Gemini API.
  • SPSS (.SAV): Mesin ini dapat mendeteksi file SPSS secara cerdas dan memberikan panduan konversi ke format yang dapat diurai sistem (CSV/XLSX).

Note: Versi ini mengeksekusi integrasi Client-Server secara aman melalui Vercel API Gateway yang melindungi kerahasiaan kunci akses LLM.
