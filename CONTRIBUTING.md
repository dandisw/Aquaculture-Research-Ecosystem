# Contributing to AREs

First off, thank you for considering contributing to the **Aquaculture Research Ecosystem (AREs)**! We highly value the support from the research community, academics, and developers to make this tool better, more accurate, and more accessible for everyone.

This document outlines the basic guidelines for contributing to this project.

## 🐛 Reporting Bugs

If you find a calculation error, a user interface (UI) glitch, or any other bug:
1. Ensure you are using the latest version of AREs.
2. Check the [Issues](https://github.com/dandisw/Aquaculture-Research-Ecosystem/issues) page to verify if the issue has already been reported.
3. If it hasn't, please open a new Issue. Provide clear and detailed information:
   - A clear description of the problem.
   - Exact steps to reproduce the issue.
   - Screenshots, if applicable.
   - The OS and browser version you are using.

## 💡 Suggesting Enhancements

Have an idea for a new statistical feature, a bioinformatics tool, or an aquaculture module? We'd love to hear it!
1. Open the [Issues](https://github.com/dandisw/Aquaculture-Research-Ecosystem/issues) page.
2. Create a new issue and use the `enhancement` or `feature request` label.
3. Explain in detail how the feature should work, the mathematical formulas or algorithms involved, and please include references to scientific literature (journals/books) if applicable.

## 💻 Development Setup

AREs is built as a pure Progressive Web Application (PWA). There is no complex build pipeline (like Webpack or Node.js) required to start developing.
